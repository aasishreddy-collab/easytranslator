# App outcomes

- [x] **Language controls and source entry:** Provide source and target selectors for English and Hindi, Bengali, Telugu, Marathi, Tamil, Urdu, Gujarati, Kannada, Odia, Malayalam, Punjabi, Assamese, Sanskrit, Sindhi, Konkani, Manipuri, Nepali, Bodo, Dogri, Santali, Maithili, Bhojpuri, Awadhi, Garhwali, Kumaoni, and Tulu, with valid Hindi and Bengali defaults. Let users type source text; detect its language automatically for translation.
- [x] **Continuous voice-to-text and silence stop:** Use continuous browser speech recognition with interim and finalized transcript updates. Keep recognized words synchronized in the source text field as the user speaks and support the selected language, including `en-IN` where available. Reset a 2.5-second inactivity timer whenever a new speech result arrives. After a 2.5-second gap without speech, stop the microphone and recognition session, finalize any remaining interim transcript, then automatically translate and speak the pending recognized segment without requiring the Translate button. Keep the mic stopped until the user explicitly activates it again. Recognition may recover from browser session restarts while the user is actively speaking, but must not restart after the silence stop or an explicit stop. If recognition is unsupported or microphone permission is denied, keep typed input usable and show clear compatibility/permission guidance.
- [x] **Conversation translation and states:** Translate each newly finalized spoken segment using Manus Core LLM after the pause; append each successful segment to the translated conversation and speak it, without retranslating previously translated segments. When available, include only the preceding 800 source characters as context for resolving references; do not translate or repeat that context. Preserve every meaningful word/detail, conversational intent, tone, idioms, repetitions, names, numbers and formatting, and use fluent native-sounding phrasing in English or any listed Indian language; do not summarize, omit, invent, or add commentary. Continue to support manual typed translation. Validate non-empty input up to 5,000 characters and a supported target language; show progress and recoverable errors without discarding the source text. Keep failed segments available for individual retry without replacing successful translations. The existing LLM is prompt-guided, not fine-tuned by this app.
- [x] **Playback, swap, and responsive app:** Speak translated text with browser speech synthesis; prefer a male voice matching the requested language when browser voice metadata identifies one, preferring exact and same-language regional matches. If voice gender is unavailable, fall back to the closest available voice for that language rather than a different language. Support replay/listen controls and a swap action that exchanges selected languages and the available source/translated text. Keep the translator responsive across phone and desktop layouts and make voice, loading, error, and focus states legible.
- [x] **App branding and page title:** Show Easy Translate in the site wordmark, browser title, route title, package name, server startup log, and project documentation. The Preview hostname is platform-assigned and remains unchanged when the site label changes.
